# 庄周梦蝶 — 四境叙事设计

> 配置源：`Assets/StoryText/story_config.json` 与 `Unreal/ButterflyDream/Content/StoryText/story_config.json`
>
> 当前版本：2.0.0，四境、28 条唯一文本。运行需要 UE5.8，不是独立 EXE。

## 一、叙事范围

玩家控制蝴蝶依次经历星海、水墨、琉璃、太极四境。第一张樱花地图及其七条文本已从当前版本移除，不再以“五境/35句”描述当前作品。

```text
梦之境 → 梦之悟 → 梦之幻 → 梦之醒
  星海     水墨     琉璃     太极
```

| 场景 | 核心主题 | 情感基调 |
|---|---|---|
| 星海 | 蝴蝶穿越星河，感受无涯 | 开阔、敬畏、深邃 |
| 水墨 | 在山体、琴桥与云谷间悟道 | 沉静、顿悟、超然 |
| 琉璃 | 在晶体浮岛与折射中辨别真假 | 迷离、克制、华丽 |
| 太极 | 万物齐一，梦与觉合 | 磅礴、了悟、圆满 |

## 二、文本与出处

每境保留 7 条，共 28 条唯一 ID。准确版权口径是：**原创文字与公有领域原典、化用混合**，不是“28 句全部原创”。

明确包含：

- 《庄子》相关原典或化用，例如“方生方死，方死方生”“天地与我并生”“万物与我为一”“蝶梦庄周，庄周梦蝶”。
- 白居易诗意化用，例如“花非花，雾非雾”。
- 为四境空间、飞行和门链编写的引导文字。

星海首句已改为“振翅越境，忽入星河”，不再描述从樱花地图进入。各境末句继续引导下一段飞行，但门链必须由玩家蓄能并穿越，不能由文字自动传送。

完整文本以 JSON 为唯一事实源，本文不另复制一套容易产生偏差的句子清单。

## 三、呈现方式

旧实现会在出生后 0.5 秒于玩家正前方生成大诗卷，并同时复制到 HUD，造成遮挡和重复。当前版本改为：

- 开场与路径里程碑均以短 HUD 回响呈现。
- 不在蝴蝶正前方自动生成大诗卷。
- 不在世界与 HUD 同时重复同一内容。
- 同一条文本在当前地图只触发一次；重新开始地图后才重新计算。
- 逐条触发、文字完整性和实际可读性必须通过 UE 实机验证，不能只凭 JSON 数量验收。

`UButterflyStorySubsystem` 仍负责场景识别、JSON 加载、路径里程碑和触发历史。路点由出生点到前门的路径生成；JSON 中的 `trigger_distance_m`、位置偏移和特效 ID 不得被描述为已完整实现的功能，除非代码与实机同时证明。

## 四、字体与配色

当前只使用实际随附并带 OFL 文本的字体：

| 字体 | 配置名 | 用途 |
|---|---|---|
| 马善政毛笔楷书 | `MaShanZheng` | 主要诗句与原典强调 |
| 站酷小薇体 | `ZCOOLXiaoWei` | 普通叙事、标题与说明 |
| 芷芒行书 | `ZhiMangXing` | 印章及预留装饰用途 |

旧的 `LXGW_WenKai`、`LXGW_WenKai_GB`、`Source_Han_Serif` 声明已移除，因为对应文件并未随附。不得再把未安装字体写成正在使用。

| 场景 | 主要文字色 | 氛围色 |
|---|---|---|
| 星海 | 星蓝、淡紫 | 深蓝与局部青碧 |
| 水墨 | 墨金、宣纸色 | 墨灰与局部暖光 |
| 琉璃 | 琉璃紫、晶蓝 | 暗紫与局部虹彩 |
| 太极 | 纯白、金色 | 虚空黑与局部金白 |

文字光晕不得吞掉笔画或与高亮背景融为一体。

## 五、与飞行和门链的关系

叙事只提供引导，不代替玩法：

1. 玩家接近门时看到共鸣提示。
2. 按住 Shift 振翅蓄能，门到安全开度后穿越。
3. 隧道中的文本不得遮住中心净空。
4. 到达隧道末端后才切换地图。
5. 返回、恢复或加载失败时，提示必须清楚且不会锁死输入。

四境门链为：星海 → 水墨 → 琉璃 → 太极 → 星海；每境返门连接上一境。

## 六、验证要求

- JSON 必须为 4 场景、28 条唯一 ID，两个副本完全一致。
- 字体名只能引用实际随附字体。
- 每境实测 7 条触发，无遗漏、无重复、无错误场景匹配。
- 1280×720 与 1920×1080 下均不遮挡主要航道，文字不超出屏幕。
- 不把旧“35句已加载”日志当作当前版本证据。
